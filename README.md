# 📝 Lista de Tarefas (To-Do List)

Uma aplicação web simples, funcional e responsiva para gerenciamento de tarefas diárias. O projeto permite criar, concluir, filtrar e deletar tarefas, ideal para manter a organização da rotina.

---

## 🚀 Funcionalidades

* **Adicionar Tarefas:** Insira novas pendências na lista.
* **Marcar como Concluída:** Alterne o status da tarefa entre pendente e concluída (com feedback visual).
* **Remover Tarefas:** Exclua tarefas da lista quando necessário.
* **Filtros Dinâmicos:** Filtre a visualização entre "Todas", "Pendentes" e "Concluídas".
* **Persistência de Dados:** (Opcional, caso use) Salva as tarefas no navegador para não perdê-las ao atualizar a página.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando a trindade clássica do desenvolvimento front-end web:

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, layout e responsividade.
* **JavaScript (ES6):** Manipulação dinâmica do DOM e lógica de gerenciamento do estado das tarefas.
